# Data Structure

A collection of data structure implementations and practice programs written in C.

## About

This repository is used to learn and practice fundamental data structures in C. It focuses on understanding core concepts, implementing basic operations, and improving programming skills through hands-on practice.

## Topics

- Sequential Lists
- Linked Lists
- Stacks
- Queues
- Trees
- Searching and Sorting Algorithms

## Language

- C

## Development Environment

- **Operating System:** Windows
- **Editor:** Visual Studio Code
- **Compiler:** GCC (MSYS2)

## Goals

- Understand fundamental data structures and their operations.
- Practice implementing data structures from scratch.
- Improve problem-solving and programming skills.
- Build a solid foundation for further computer science studies.
